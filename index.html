A camera above the keyboard sees both what a pianist plays and how: which keys go down, and which finger presses each one. We want a model that reads both from silent video, without a microphone or MIDI. Two things were missing. First, there was little video in which both the notes and the fingers are labeled, so we recorded PianoVid-R: 80 pianists on a Disklavier, filmed from above, with the MIDI taken directly from the instrument and finger labels for almost every note derived from the video. Second, visual transcription models usually squeeze each frame into one feature vector before predicting notes, which loses track of which part of the image belongs to which key, exactly the information needed to tell fingers apart. PianoLite keeps one feature per key throughout the network, and the same features give both the notes and the fingers. It transcribes more accurately than earlier visual methods, recognizes the finger for each note, and copes better with pianos it has never seen.
